# Cafetin-central-web
Segunda fase de Proyecto
 Cafetín Central - UCV

Proyecto interactivo que simula el sistema de pedidos y gestión del Cafetín Central de la UCV. Cuenta con módulos para clientes, administración y caja.

## 🔑 Accesos de prueba:
- Cliente: ClienteUCV / Central_123
- Admin: adminRoot / cafetinAdmin
- Caja: caja_01 / Cajero#123

---
Aclaratoria: Para el desarrollo de la lógica de este proyecto y la optimización de funciones en JavaScript, se contó con el apoyo de IA (Gemini) como herramienta de asistencia técnica.
